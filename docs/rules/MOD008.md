# MOD008 — File-Scoped Namespace

**Category:** Structure  
**Minimum C# Version:** 10.0  
**EditorConfig Keys:** `csharp_style_namespace_declarations`

## Description

Detects traditional namespace blocks (with braces) and suggests converting to file-scoped namespace declarations to reduce one level of indentation.

## Before

```csharp
using System;

namespace MyApp.Services
{
    public class UserService
    {
        public void DoWork()
        {
            // ...
        }
    }
}
```

## After

```csharp
using System;

namespace MyApp.Services;

public class UserService
{
    public void DoWork()
    {
        // ...
    }
}
```

## Conditions

- Only suggests when there is exactly **one** namespace in the file
- Does not suggest when there are nested namespaces
- Respects `csharp_style_namespace_declarations = block_scoped` in `.editorconfig`

## When This Rule Is Suppressed

- When `.editorconfig` sets `csharp_style_namespace_declarations` to `block_scoped`
- When the file contains multiple or nested namespaces

## Configuration

```yaml
rules:
  MOD008:
    enabled: true
    severity: suggestion
```
