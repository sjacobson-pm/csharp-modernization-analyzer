# MOD005 — Switch Expressions

**Category:** Control flow  
**Minimum C# Version:** 8.0  
**EditorConfig Keys:** None

## Description

Detects multi-branch if/else chains that compare the same variable against constants and can be replaced with a switch expression.

## Before

```csharp
string GetLabel(int status)
{
    if (status == 1)
        return "Active";
    else if (status == 2)
        return "Pending";
    else if (status == 3)
        return "Closed";
    else
        return "Unknown";
}
```

## After

```csharp
string GetLabel(int status) => status switch
{
    1 => "Active",
    2 => "Pending",
    3 => "Closed",
    _ => "Unknown",
};
```

## When This Rule Is Suppressed

- When the if/else chain has fewer than 3 branches
- When branches contain complex logic beyond simple returns
- When the rule is disabled in `.modernization.yml`

## Configuration

```yaml
rules:
  MOD005:
    enabled: true
    severity: suggestion
```
