# MOD002 — Null-Conditional and Null-Coalescing Operators

**Category:** Null handling  
**Minimum C# Version:** 6.0  
**EditorConfig Keys:** `dotnet_style_null_propagation`, `dotnet_style_coalesce_expression`

## Description

Detects explicit null checks that can be replaced with the null-conditional (`?.`) operator or null-coalescing (`??`) operator for more concise and readable code.

## Before

```csharp
if (customer != null)
{
    customer.SendEmail();
}

string name = input != null ? input : "default";
```

## After

```csharp
customer?.SendEmail();

string name = input ?? "default";
```

## When This Rule Is Suppressed

- When `.editorconfig` sets `dotnet_style_null_propagation` to `false`
- When `.editorconfig` sets `dotnet_style_coalesce_expression` to `false`

## Configuration

```yaml
rules:
  MOD002:
    enabled: true
    severity: suggestion
```
