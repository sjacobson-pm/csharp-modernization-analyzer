# MOD012 — Primary Constructors

**Category:** Constructors  
**Minimum C# Version:** 12.0  
**EditorConfig Keys:** None

## Description

Detects classes with constructors that only assign parameters to readonly fields (typical dependency injection pattern) and suggests using primary constructors.

## Before

```csharp
public class UserService
{
    private readonly IUserRepository _repository;
    private readonly ILogger<UserService> _logger;
    private readonly IMapper _mapper;

    public UserService(
        IUserRepository repository,
        ILogger<UserService> logger,
        IMapper mapper)
    {
        _repository = repository;
        _logger = logger;
        _mapper = mapper;
    }

    public async Task<User> GetUserAsync(int id)
    {
        _logger.LogInformation("Getting user {Id}", id);
        return await _repository.GetByIdAsync(id);
    }
}
```

## After

```csharp
public class UserService(
    IUserRepository repository,
    ILogger<UserService> logger,
    IMapper mapper)
{
    public async Task<User> GetUserAsync(int id)
    {
        logger.LogInformation("Getting user {Id}", id);
        return await repository.GetByIdAsync(id);
    }
}
```

## Conditions

- Constructor body only contains field assignments (`this._field = param;`)
- All assigned fields are `readonly`
- One-to-one mapping between parameters and fields

## When This Rule Is Suppressed

- When the constructor has logic beyond simple assignment
- When fields are not readonly
- When using C# < 12.0

## Configuration

```yaml
rules:
  MOD012:
    enabled: false    # commonly disabled until teams adopt C# 12
    severity: suggestion
```
