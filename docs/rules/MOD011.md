# MOD011 — Raw String Literals

**Category:** Strings  
**Minimum C# Version:** 11.0  
**EditorConfig Keys:** None

## Description

Detects string literals that contain multiple escape sequences (e.g., `\\`, `\"`, `\n`) or span multiple lines via concatenation, and suggests using C# 11 raw string literals (`"""..."""`) for improved readability.

## Before

```csharp
var path = "C:\\Users\\Admin\\Documents\\report.txt";
var json = "{\n  \"name\": \"test\",\n  \"value\": 42\n}";
var regex = "\\d{3}-\\d{3}-\\d{4}";
```

## After

```csharp
var path = """C:\Users\Admin\Documents\report.txt""";
var json = """
    {
      "name": "test",
      "value": 42
    }
    """;
var regex = """\d{3}-\d{3}-\d{4}""";
```

## When This Rule Is Suppressed

- When the string has only one or two escape sequences
- When the string contains interpolation that would require `$"""` syntax awkwardly
- When the rule is disabled in `.modernization.yml`

## Configuration

```yaml
rules:
  MOD011:
    enabled: true
    severity: suggestion
```
