# MOD009 — Target-Typed `new()`

**Category:** Typing  
**Minimum C# Version:** 9.0  
**EditorConfig Keys:** None

## Description

Detects object creation expressions where the type is redundantly specified on both sides of the assignment and can be replaced with `new()` (target-typed new).

## Before

```csharp
private readonly List<string> _items = new List<string>();
Dictionary<string, int> counts = new Dictionary<string, int>();
CancellationTokenSource cts = new CancellationTokenSource();
```

## After

```csharp
private readonly List<string> _items = new();
Dictionary<string, int> counts = new();
CancellationTokenSource cts = new();
```

## When This Rule Is Suppressed

- When the type is not apparent from the left-hand side (e.g., `var` or interface type)
- When the constructor has arguments that make the type useful for documentation
- When the rule is disabled in `.modernization.yml`

## Configuration

```yaml
rules:
  MOD009:
    enabled: true
    severity: suggestion
```
