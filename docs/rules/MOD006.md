# MOD006 — Using Declarations

**Category:** Resource management  
**Minimum C# Version:** 8.0  
**EditorConfig Keys:** None

## Description

Detects `using` block statements that can be converted to `using` declarations, reducing nesting and improving readability when the resource lifetime extends to the end of the enclosing scope.

## Before

```csharp
public void ProcessFile(string path)
{
    using (var stream = File.OpenRead(path))
    {
        using (var reader = new StreamReader(stream))
        {
            var content = reader.ReadToEnd();
            Console.WriteLine(content);
        }
    }
}
```

## After

```csharp
public void ProcessFile(string path)
{
    using var stream = File.OpenRead(path);
    using var reader = new StreamReader(stream);
    var content = reader.ReadToEnd();
    Console.WriteLine(content);
}
```

## When This Rule Is Suppressed

- When the resource must be disposed before the end of the method
- When there is code after the using block that should not have access to the resource
- When the rule is disabled in `.modernization.yml`

## Configuration

```yaml
rules:
  MOD006:
    enabled: true
    severity: suggestion
```
