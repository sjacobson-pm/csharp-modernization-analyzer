# MOD007 — Null-Coalescing Assignment

**Category:** Null handling  
**Minimum C# Version:** 8.0  
**EditorConfig Keys:** None

## Description

Detects if-null-then-assign patterns that can be replaced with the null-coalescing assignment operator (`??=`).

## Before

```csharp
if (_cache == null)
{
    _cache = new Dictionary<string, object>();
}

if (connection == null)
    connection = CreateConnection();
```

## After

```csharp
_cache ??= new Dictionary<string, object>();

connection ??= CreateConnection();
```

## When This Rule Is Suppressed

- When the null check has side effects or additional logic
- When the rule is disabled in `.modernization.yml`

## Configuration

```yaml
rules:
  MOD007:
    enabled: true
    severity: suggestion
```
