# MOD003 — String Interpolation

**Category:** Strings  
**Minimum C# Version:** 6.0  
**EditorConfig Keys:** None

## Description

Detects `string.Format()` calls that can be replaced with string interpolation (`$"..."`) for improved readability.

## Before

```csharp
var message = string.Format("Hello {0}, you have {1} items", name, count);
var log = string.Format("Error at {0}: {1}", DateTime.Now, ex.Message);
```

## After

```csharp
var message = $"Hello {name}, you have {count} items";
var log = $"Error at {DateTime.Now}: {ex.Message}";
```

## When This Rule Is Suppressed

- When format strings are used with localization/resource files
- When the rule is disabled in `.modernization.yml`

## Configuration

```yaml
rules:
  MOD003:
    enabled: true
    severity: suggestion
```
