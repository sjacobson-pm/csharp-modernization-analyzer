# MOD004 — Pattern Matching

**Category:** Pattern Matching  
**Minimum C# Version:** 7.0  
**EditorConfig Keys:** `csharp_style_pattern_matching_over_is_with_cast_check`, `csharp_style_pattern_matching_over_as_with_null_check`

## Description

Detects `is` type checks followed by casts, and `as` conversions followed by null checks, suggesting modern pattern matching instead.

## Before — `is` with cast

```csharp
if (shape is Circle)
{
    var circle = (Circle)shape;
    return circle.Radius * Math.PI;
}
```

## After

```csharp
if (shape is Circle circle)
{
    return circle.Radius * Math.PI;
}
```

## Before — `as` with null check

```csharp
var circle = shape as Circle;
if (circle != null)
{
    return circle.Radius * Math.PI;
}
```

## After

```csharp
if (shape is Circle circle)
{
    return circle.Radius * Math.PI;
}
```

## When This Rule Is Suppressed

- When `.editorconfig` sets `csharp_style_pattern_matching_over_is_with_cast_check` to `false`
- When `.editorconfig` sets `csharp_style_pattern_matching_over_as_with_null_check` to `false`

## Configuration

```yaml
rules:
  MOD004:
    enabled: true
    severity: suggestion
```
