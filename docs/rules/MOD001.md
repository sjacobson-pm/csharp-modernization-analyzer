# MOD001 — Prefer `var`

**Category:** Typing  
**Minimum C# Version:** 3.0  
**EditorConfig Keys:** `csharp_style_var_for_built_in_types`, `csharp_style_var_when_type_is_apparent`, `csharp_style_var_elsewhere`

## Description

Suggests using `var` for local variable declarations where the type is apparent from the right-hand side or where EditorConfig preferences indicate `var` should be used.

## Before

```csharp
List<string> names = new List<string>();
Dictionary<string, int> counts = GetCounts();
string message = "hello";
```

## After

```csharp
var names = new List<string>();
var counts = GetCounts();
var message = "hello";
```

## When This Rule Is Suppressed

- When `.editorconfig` sets `csharp_style_var_*` to `false`
- When the type is not apparent from context and `csharp_style_var_elsewhere` is `false`

## Configuration

```yaml
rules:
  MOD001:
    enabled: true
    severity: suggestion
```
