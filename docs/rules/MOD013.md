# MOD013 — Explicit Lambda Return Type

**Category:** Lambdas  
**Minimum C# Version:** 10.0  
**EditorConfig Keys:** None

## Description

Detects lambda expressions whose entire body is a cast expression and suggests using C# 10's explicit lambda return type syntax instead. This moves type information from the body to the signature, making the lambda's contract clearer.

## Before

```csharp
var selector = paths.Select(path => (MetadataReference)MetadataReference.CreateFromFile(path));
Func<string, object> fn = static s => (object)s.ToUpper();
var transform = items.Select((item, i) => (IResult)Process(item, i));
```

## After

```csharp
var selector = paths.Select(MetadataReference (path) => MetadataReference.CreateFromFile(path));
Func<string, object> fn = static object (s) => s.ToUpper();
var transform = items.Select(IResult (item, i) => Process(item, i));
```

## When This Rule Is Suppressed

- When the lambda is `async` (return type semantics differ with `Task<T>`)
- When the lambda already has an explicit return type
- When the rule is disabled in `.modernization.yml`

## Configuration

```yaml
rules:
  MOD013:
    enabled: true
    severity: suggestion
```
