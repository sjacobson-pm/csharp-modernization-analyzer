# MOD010 — Collection Expressions

**Category:** Collections  
**Minimum C# Version:** 12.0  
**EditorConfig Keys:** None

## Description

Detects explicit collection initialization syntax that can be replaced with C# 12 collection expressions (`[...]`) for more concise code.

## Before

```csharp
int[] numbers = new int[] { 1, 2, 3, 4, 5 };
var names = new List<string> { "Alice", "Bob" };
string[] empty = Array.Empty<string>();
var combined = first.Concat(second).ToArray();
```

## After

```csharp
int[] numbers = [1, 2, 3, 4, 5];
List<string> names = ["Alice", "Bob"];
string[] empty = [];
string[] combined = [..first, ..second];
```

## When This Rule Is Suppressed

- When targeting a C# version below 12.0
- When the collection type doesn't support collection expressions
- When the rule is disabled in `.modernization.yml`

## Configuration

```yaml
rules:
  MOD010:
    enabled: true
    severity: suggestion
```
